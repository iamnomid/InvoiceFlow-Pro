# InvoiceFlow Pro V4 — راهنمای فارسی

## این نسخه چه چیزهای تازه‌ای دارد؟
- داشبورد تازه با ۴ شاخص و نمودار وضعیت پردازش
- جست‌وجو و فیلتر بر اساس وضعیت فاکتور
- تشخیص **فاکتور تکراری احتمالی** با تطبیق نام فروشنده و شماره فاکتور
- قرار دادن **همه نسخه‌های تکراری** در `Needs review` تا جمع مبالغ دوبار محاسبه نشود
- خروجی Excel سه‌شیتی و خروجی CSV مخصوص موارد نیازمند بررسی

## روش اجرا روی Windows / VS Code

۱. فایل zip را Extract All کن. پوشه `InvoiceFlow_Pro_V4` را در VS Code باز کن.
۲. اگر برنامه نسخه قبلی اجراست، در ترمینال آن Ctrl+C بزن.
۳. در ترمینال همین پوشه، دستورهای زیر را اجرا کن:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## تست شماره ۱: شش فاکتور بدون تکرار

۶ PDF پوشه samples را انتخاب کن، **به‌جز `INV-1001_DUPLICATE.pdf`**.

نتیجه مورد انتظار: 6 PDF / 4 Complete / 2 Needs review / $598.50.

## تست شماره ۲: هفت فایل با یک تکراری

هر **۷ فایل PDF** در پوشه `samples` را آپلود کن.

نتیجه مورد انتظار: 7 PDF / 3 Complete / 4 Needs review / $473.50.

در تب Review needed چهار مورد هست:
- `INV-1004` با مبلغ خالی
- `INV-1006` با ارز EUR
- `INV-1001` و `INV-1001_DUPLICATE` با علت `Potential duplicate`

**دلیل عدد 473.50:** دو نسخه از فاکتور شماره ۱۰۰۱، تا قبل از تصمیم انسان، هر دو از جمع خودکار حذف می‌شوند.

## تست آفلاین

```powershell
.\.venv\Scripts\python.exe test_samples.py
```

## محدودیت‌های مهم

- فقط PDFهای متنی انگلیسی؛ هنوز OCR ندارد.
- برای ارقام دلار USD طراحی شده و دیگر ارزها را برای بررسی انسانی علامت‌گذاری می‌کند.
- تشخیص تکراری بر اساس شماره فاکتور و نام فروشنده است، **فقط احتمالی** و نیازمند تأیید انسانی.
- عبارت `Validated-format` یعنی آزمون فرمت و فیلدها موفق بوده، نه اینکه سند از نظر حقوقی یا مالی تأیید شده باشد.
- داده‌ها ساختگی و مخصوص تست‌اند. برای دموی عمومی از فاکتور محرمانه استفاده نکن.
- در این نسخه هنوز تأیید فایل‌های رمزدار، قالب‌های پیچیده و فاکتورهای واقعی با نمونه زیاد بررسی نشده است.
